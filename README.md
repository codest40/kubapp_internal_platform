# KUBAPP

KUBAPP is a Kubernetes-based application delivery platform that brings together cloud infrastructure provisioning, CI/CD, GitOps, and observability to simplify how applications are built, deployed, and operated.
Each major section of the platform has its own README.

## Core Principles

Security, cost efficiency, and operational simplicity guide the platform's design.

## What It Does

- Automates cloud infrastructure provisioning and management through Infrastructure as Code.
- Validates, builds, packages, and deploys applications through CI/CD and GitOps.
- Provides monitoring and observability for operational visibility.
- Keeps platform operations maintainable, debuggable, and extensible.
- Applies defined policies and execution boundaries to automated operations.
