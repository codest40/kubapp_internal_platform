# Apply Argo Secret
### What It Does

The apply_argo_secret.py script applies the required ArgoCD secret
configuration to the Kubernetes cluster.

### What It Expects to Already Exist

The script expects:

- Python to be available.
- The required Python dependencies to be installed.
- kubectl to be installed and configured.
- Access to the target Kubernetes cluster.
- The required secret/configuration input expected by the script to already exist.
